ORBIT PERSONAL v2.7.0 — CATATAN PEMERIKSAAN

Pembaruan:
- Label hari pada grafik produktivitas dibuat lebih kontras dan tebal.
- Arahkan kursor ke batang grafik untuk tooltip native berisi tanggal, jumlah tugas selesai, dan nama tugas yang tercatat selesai pada tanggal itu. Batang juga dapat difokuskan dengan keyboard.
- Ikon aplikasi PWA diperbarui menggunakan ikon Orbit minimal violet yang disepakati; file ikon 192x192 dan 512x512 dibuat ulang.
- Checklist subtugas tidak lagi tampil sebagai blok berbingkai; teks dibuat lebih besar, kontras, dan mudah membungkus baris.
- Cache service worker dinaikkan ke v2.7.0.

Pemeriksaan yang dilakukan:
- JavaScript inline lolos pemeriksaan sintaks Node.js.
- Arsip ZIP lolos pemeriksaan integritas.
- Manifest JSON valid dan menunjuk ikon 192x192 serta 512x512.
- Cache service worker menunjukkan versi v2.7.0.
- LocalStorage key orbitdesk.workspace.v1 tetap ada.
- Struktur import/export JSON yang ada pada sumber tetap dipertahankan.

Batasan:
- Uji interaksi browser penuh tidak dapat diselesaikan di lingkungan ini. Tooltip native SVG bergantung pada dukungan browser; lakukan pemeriksaan akhir di Chromebook setelah deployment.
- Grafik hanya menampilkan aktivitas yang bisa disimpulkan dari tugas dengan status selesai dan completedAt/updatedAt pada data lokal; tidak membuat riwayat aktivitas baru secara retroaktif.
